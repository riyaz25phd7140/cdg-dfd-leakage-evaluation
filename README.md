# CDG-DFD: a leakage-controlled evaluation of frequency-based deepfake detection

Code for the paper "A Leakage Controlled Evaluation of Cross Domain Generalization in Frequency Based Deepfake Detection for Unseen GAN and Diffusion Models" by Shaik Riyaz Ahamed and Monalisa Sahu (VIT-AP University).

All code, Kaggle notebooks, figure scripts and full instructions are in the [`cdg-dfd-revision`](cdg-dfd-revision) folder. Start with its [README](cdg-dfd-revision/README.md).
